# NovaMicrofinance - Projet réseau d'entreprise

Projet fil rouge de formation d'ingénieur système et réseau : conception, déploiement, sécurisation et automatisation du système d'information d'une institution de microfinance multi-sites.

## Contexte

NovaMicrofinance est une institution de microfinance (~200 employés) avec un siège et 2 agences. Le projet couvre le réseau, les systèmes, le cloud, l'automatisation et la sécurité.

## Phases du projet

| Phase | Contenu | Statut |
|---|---|---|
| 0 | Cadrage et cahier des charges | Terminée |
| 1 | Conception : plan d'adressage, VLSM | À faire |
| 2 | Réseau LAN/WAN (CCNA) | À faire |
| 3 | Réseau avancé (CCNP) | À faire |
| 4 | Services système (Linux, Windows Server) | À faire |
| 5 | Virtualisation et cloud | À faire |
| 6 | Automatisation (Python, Ansible, CI/CD) | À faire |
| 7 | Sécurité (firewall, VPN) | À faire |

## Structure du dépôt

- `01-conception/` : plan d'adressage, schémas
- `02-reseau/` : configurations et fichiers de lab
- `03-systemes/` : Linux et Windows Server
- `04-cloud/` : extension cloud
- `05-automatisation/` : scripts et playbooks
- `06-securite/` : firewall, VPN, politiques
- `docs/` : cahier des charges, procédures, captures
